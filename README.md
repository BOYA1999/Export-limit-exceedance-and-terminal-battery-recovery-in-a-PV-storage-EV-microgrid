# Reproducibility repository

This repository contains source code, modeled inputs, recorded numerical artifacts and verification scripts. Manuscript text, supplementary article text, figure assets and author materials are intentionally excluded.

## Verify the supplied records

Use Python 3.12 and the versions in `requirements.txt`. From the repository root, run `python verify_package.py` and `python verify_revision.py`. These checks validate file hashes, recorded arrays, solver logs, checkpoints and revision artifacts.

No figure assets are included in this computational upload.
